Projetos

Neurônio do zero em Python: classificação de tumores de mama. Regressão logística com um único neurônio artificial e função sigmoide, implementada do zero com Python e NumPy: divisão em treino e teste, normalização, cálculo do gradiente e atualização dos pesos por gradiente descendente. Dataset Breast Cancer Wisconsin (569 amostras, 30 características); o Scikit-learn foi usado só para carregar os dados. 96,49% de acurácia em um conjunto de teste independente. Projeto educacional, não é uma ferramenta de diagnóstico.

Landing Page de Vendas com Pagamentos Integrados (projeto em equipe). Astro, TypeScript, API REST e SQLite. Integração backend com a API do Mercado Pago usando webhooks assíncronos, atualizando o status de pagamento em tempo real no banco.

NeuroHug (projeto em equipe). .NET, FastAPI e SQLite. Contribuí com o módulo de controle de acesso (RBAC) para três perfis de usuário, com validação de tokens e tratamento de exceções HTTP. Também propus o uso do Figma para a prototipação das telas.

Micro Core Utils. C, Linux e chamadas de sistema POSIX. Quatro utilitários Unix (cat, echo, wc, grep) feitos do zero, usando open, read, write e close, com gestão manual de buffers e descritores de arquivo.

Sistema de Navegação Cirúrgica para Cálculo Renal (projeto acadêmico, UFABC). Python, Unity, Modelagem 3D e Realidade Virtual. Adaptação de um projeto de planejamento de trajetória para ureteroscópio flexível, originado em uma pesquisa de doutorado: exportação das estruturas anatômicas e trajetórias em .obj e integração dos modelos ao Unity para visualização e interação em VR.
